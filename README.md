## 🎨 About This Site

A single-page, responsive portfolio built with plain HTML, **Tailwind CSS** (CDN), **Font Awesome** and the **Sora** font. No build step is needed.

**Sections:** Introduction · Skills · Projects · Experience & Achievements · Education · Contact

**Highlights:**
- Dark, glass-style design with scroll-reveal animations
- Fully responsive, with a mobile menu
- Respects `prefers-reduced-motion`
- Content is rendered from simple JavaScript arrays, so it's easy to update

## 🛠️ Run Locally

```bash
git clone https://github.com/PritySingh303132/pritysingh303132.github.io.git
cd pritysingh303132.github.io
```

Open `index.html` in your browser. That's it. An internet connection is needed for the CDN fonts and styles.

## 📦 Deploy (GitHub Pages)

1. Keep the repository named `pritysingh303132.github.io`.
2. Make sure `index.html` is at the root of the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live in 1–2 minutes at `https://pritysingh303132.github.io/`.
